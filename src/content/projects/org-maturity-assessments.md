An ongoing clinic offering short, structured diagnostics for small and mid-sized non-profits — covering data governance, security posture, team capacity, and tooling. Each assessment produces a prioritised set of investments an organisation can act on inside a single funding cycle.

The format is deliberately lightweight: two weeks, a few interviews, a focused readout. It's designed to be a useful first step, not a consulting engagement.
